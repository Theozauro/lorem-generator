# Lorem Ipsum Generator for Designers

A single-page, browser-only Lorem Ipsum utility built with React, TypeScript, and Vinext. Set Words and Paragraphs together to generate the exact word total across naturally varied paragraphs. The main result updates as settings change, while Regenerate creates a fresh variation with the same settings. Character and sentence modes, text matching and expansion, stress-test content, type specimens, and a live slider-controlled Fit to Box preview are also included.

The page includes four visual advertisement placeholders for layout review: two wide-screen side rails and two responsive slots around the full-width Fit to Box tool. They contain no AdSense scripts or ad requests. The warm light and dark themes follow the system preference by default, with a locally saved manual override. A semantic FAQ, expandable privacy/cookie/GDPR information, and a local-storage consent notice sit above and inside the footer for the European launch review.

## Run locally

Requires Node.js 22.13 or newer.

```bash
npm install
npm run dev
```

Open the local URL shown in the terminal. No accounts, API keys, database, or backend services are required.

## Production build

```bash
npm run build
```
